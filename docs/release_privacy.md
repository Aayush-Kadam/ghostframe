# Release privacy review

The source candidate is a selected portable snapshot, not a Git history bundle. Reproduce its automated checks with `python scripts/release_scan.py . --output ../source-scan.json` or pass the candidate ZIP as the first argument. Pattern checks are supplemented by review of meaningful matches and genuine browser screenshots; this is not universal secret detection.

Copied historical reports and manifests had identifying home/workspace prefixes replaced with portable placeholders in the remediation branch. Original raw evidence, the unchanged audited baseline and original M9 failures remain preserved separately. These sanitized copies are not substituted for the originals as historical evidence. Synthetic event IDs, versions, build numbers, relative filenames, virtual /documents paths, hashes and observed outcomes are retained because they support reproducibility without identifying a local account.

Distribution excludes virtual environments, npm modules, caches, temporary databases, raw diagnostic captures, private forensic directories, historical milestone payloads, unnecessary generated reports and all .git/history bundles. Current source, tests, manifests/lockfile, compiled frontend, MIT/third-party notices, current benchmark outputs, eight genuine sanitized screenshots and current documentation remain. No screenshot was edited to conceal a failure; the original failing screenshot remains in the preserved M9 audit, while replacement screenshots are new captures of the corrected application.

The performed historical scan found home/workspace references in preserved Git objects, with no private-key pattern hit. They are identifying metadata, not evidence of an exposed password. Git history has not been rewritten. **Do not describe the historical repository as privacy-clean or publish that history merely because this source ZIP passed its scan.** It is excluded from the proposed distribution, so no history-rewrite operation is needed for this candidate. Any future public-history decision requires explicit owner scope/authorization.

Current scan counts, selected-file manifest, sanitizer list, private history review and archive verification are recorded in the M9-RC handoff. Pattern scans cannot establish that all conceivable credentials are absent. Bundled examples deliberately contain synthetic canaries; do not replace them with real credentials. Raw local diagnostic outputs may expose filesystem paths and must remain private.
